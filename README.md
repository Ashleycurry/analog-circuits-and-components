## 内容概览

### 第一章：电学基础

- 理解电流、电压、电阻和电路的基本概念。
- 区分直流电与交流电、弱电与强电。
- 了解通路、断路、短路和家庭电路的基本组成。
- 掌握欧姆定律、功率计算、焦耳定律。
- 理解串联电路和并联电路的基本特点。

### 第二章：常见电子元器件

- 使用电路仿真软件观察基础电路行为。
- 认识电阻器的阻值、功率、精度和阻值识别方法。
- 了解固定电阻、可变电阻和光敏电阻、热敏电阻、压敏电阻等特种电阻。
- 认识电容器的容量、耐压、容差，以及固定电容、可变电容和超级电容。
- 理解电感器的储能、通直隔交特性和感抗。
- 了解磁珠、继电器、保险丝、接插件和轻触按键。
- 了解蜂鸣器、有源与无源蜂鸣器的区别。
- 认识晶振、电池和稳压电源芯片的基本参数。
- 掌握万用表的基本功能、测量方法和安全注意事项。

### 第三章：模拟电路基础

- 区分连续的模拟信号与离散的数字信号。
- 理解模拟电路在信号滤波、放大和传递中的作用。
- 理解二极管的单向导通特性。
- 了解发光二极管、数码管和稳压二极管的使用。
- 了解 NPN、PNP 三极管的基本结构和开关原理。
- 理解 MOS 管通过电场控制电流的基本原理。
- 结合光感灯案例理解传感器信号与器件控制。

### 第四章：典型电路实践

- 压敏电阻：用于过压保护和尖峰电压钳位。
- 上拉电阻：使信号线在空闲状态保持高电平。
- 下拉电阻：使信号线在空闲状态保持低电平。
- 限流电阻：将电流限制在元器件正常工作范围内。
- 零欧姆电阻：用于跨接、调试、测量和 PCB 布线调整。
- 滤波电容：抑制电源和信号中的干扰。
- 耦合电容：隔离直流分量并传递交流信号。
- 旁路电容：为高频干扰提供旁路通道。

### 第五章：附录与工具使用

- 常用电气符号：`VCC`、`GND`、`AC`、`DC` 等。
- 直流稳压电源的输入、输出、恒压和恒流状态。
- 万用表和示波器的基础使用场景。

## 元器件选型关注点

阅读元器件数据手册时，建议至少确认以下参数：

- 工作电压和最大允许电压。
- 工作电流、最大电流和浪涌电流。
- 功率、散热条件和工作温度范围。
- 标称值、容差、精度和温度系数。
- 封装、引脚定义、极性和安装方向。
- 正常工作条件、过载条件和失效保护方式。

数据手册中的额定值和最大值是工程设计的重要边界，不能仅依据元器件外观或标称名称进行替换。

## 安全注意事项

- 强电电路和家庭电路存在触电、短路和火灾风险，不能按照低压实验电路处理。
- 测量前确认万用表档位、表笔插孔、量程和被测信号范围。
- 测量电压时禁止将表笔误插在电流测量插孔后直接并联到电源两端。
- 不要在通电状态下随意更换量程、移动元器件或改变接线。
- 对电容器、稳压电源和电池，应确认极性、耐压和放电状态。
- 实际设计和维修应以器件数据手册、实验规范和相关安全标准为准。
